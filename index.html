Unlock Code Calculator

16桁のERCコードを入力してください

使い方：

「機種を選んで確認する」をクリックすると、お使いのナビの機種に合わせた手順を確認できます。

使い方 — 機種を選択

機種共通の汎用手順

多くのトヨタ・レクサス純正ナビに対応した一般的な手順です。

  1. 1車のエンジンをかけずにACCまたはIGをONにします
  2. 2ナビのメインボタン（MENUまたはMAPボタン）を長押ししながら、パーキングライト（スモールランプ）を3〜4回ON/OFFします
  3. 3サービスモード（診断モード）画面が表示されます
  4. 4「ERC」または「セキュリティ」メニューを選択します
  5. 5画面に表示される16桁のERCコードをこのサイトに入力して計算します
  6. 6計算されたロック解除コードをナビに入力します

対応機種：NHDT-W57、NHDT-W58、NHDN-W56G、NHDN-W57G、NHDN-W58G

NHDT・NHDN系の旧型モデルに対応した手順です。

  1. 1パーキングブレーキをかけます
  2. 2イグニッション（ACC）をONにしてナビを起動します
  3. 3ナビの「MENU」ボタン（または「MAP」ボタン）を長押しし続けます
  4. 4そのまま車のパーキングライト（スモールランプ）スイッチを3回ON/OFFします（各操作は1秒以内）
  5. 5「TEST MODE」または「ERC SERVICE MODE」画面が表示されます
  6. 6画面に表示される16桁のERCコードをこのサイトに入力して計算します
  7. 7計算されたロック解除コードをナビに入力します

NHZT 系の専用手順

NHZT モデルでの操作手順です。

  1. 1パーキングブレーキをかけます
  2. 2「INFO」または「MENU」ボタンを長押しします
  3. 3長押ししたまま、ヘッドライト（またはパーキングライト）を3回ON/OFFします
  4. 4サービスメニュー（診断メニュー）が表示されます
  5. 5「Security」または「ERC入力」を選択します
  6. 6画面に表示される16桁のERCコードをこのサイトに入力して計算します
  7. 7計算されたロック解除コードをナビに入力します

対応機種：NSZT-W62G、NSZT-W64T、NSZT-W66T、NSZT-Y66T、NSZN-W64T、NSZN-W66T、NSZN-W68T、NSZN-Z66T

NSZT・NSZN系の比較的新しいモデルに対応した手順です。タッチパネル操作でサービスモードに入ります。

  1. 1イグニッション（ACC）をONにしてナビを起動します
  2. 2「MENU」ボタンを押してメインメニューを表示します
  3. 3画面の左上 → 右上 → 左下 → 右下 の順に4隅をタッチし、これを3回繰り返します（合計12回）
  4. 4サービスモード（診断モード）画面が表示されます
  5. 5「ERC入力」または「セキュリティ」を選択します
  6. 6画面に表示される16桁のERCコードをこのサイトに入力して計算します
  7. 7計算されたロック解除コードをナビに入力します

注意事項

  • ・機種によっては手順が異なる場合があります
  • ・サービスモードへの操作は自己責任で行ってください
